# Спрайты первой версии

Утверждённый визуальный набор: четыре героя и четыре тиранида. Все изображения — PNG с прозрачным фоном.

Герои представлены листами 3×3. Кадры слева направо, сверху вниз: статика, атака, получение урона, падение Уверенности, рост Уверенности, затем четыре кадра ходьбы.

Враги представлены листами 1×3: статика, атака, получение урона. Ликтор — минибосс.

Космодесантник пока без знаков конкретного ордена. Перед использованием в игре кадры нужно нарезать, выровнять и проверить в анимации.
