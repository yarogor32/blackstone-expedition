# Blackstone Expedition

A browser playtest set in a shifting Blackstone Fortress. Explore the Precipice hub, enter the Docks, choose the First Passage, walk the Aeldari Ranger through the corridor, and return through a portal.

**[Play in your browser](https://yarogor32.github.io/blackstone-expedition/)**

The site is a static build: `index.html` is the entry point, with all images, music and sound effects stored in this repository. See [GAME_README.md](GAME_README.md) for controls and asset notes. The broader concept remains in [DESIGN.md](DESIGN.md) and [TODO.md](TODO.md).
